# TelarañaMX - Ecosistemas Creativos

TelarañaMX es una plataforma web diseñada para una agencia creativa que busca conectar, atrapar y activar a las personas con las marcas a través de ecosistemas creativos únicos.

## 🚀 Características

- **Diseño Premium y Responsivo:** Adaptado para una visualización óptima en computadoras, tabletas y teléfonos móviles.
- **Menú de Navegación Inteligente:** Menú tipo "hamburguesa" dinámico para dispositivos móviles con transiciones suaves.
- **Galería de Proyectos Dinámica:** 
  - En escritorio: Efecto de "tajadas diagonales" con hover.
  - En móvil: Distribución horizontal con scroll lateral y efecto "Snap".
- **Animaciones Interactivas:** 
  - Araña animada vinculada al scroll (Parallax).
  - Carrusel de imágenes infinito y automático.
- **Navegación Fluida:** Desplazamiento suave (smooth scroll) entre secciones y logo con retorno al inicio.

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructura semántica.
- **CSS3:** Diseño responsivo, Media Queries, Variables CSS, animaciones y efectos visuales.
- **JavaScript:** Lógica del carrusel, menú hamburguesa y animaciones de scroll.

## 📂 Estructura del Proyecto

- `index.html`: Estructura principal del sitio.
- `styles.css`: Estilos globales y responsivos.
- `carrusel.js`: Lógica del carrusel infinito.
- `menu.js`: Lógica del menú hamburguesa.
- `animaciones.js`: Animación de la araña y otros efectos.
- `img/`: Directorio de recursos gráficos.
